# Συνέντευξη — тренажёр собеседования на гражданство Кипра

Тренажёр для подготовки к собеседованию на гражданство Кипра, которое проходит на греческом. Работает как PWA (можно установить на телефон) и как Telegram Mini App. Интерфейс на русском.

Идея: вы заполняете анкету о себе по-русски, приложение собирает из неё ваши ответы на 103 вопроса экзаменатора на трёх языках. Греческий — основной, английский — запасной, если забыли слово, русский — перевод. Дальше ответы заучиваются карточками с интервальным повторением, тренируются в симуляции собеседования на слух, а Telegram-бот напоминает заниматься каждый день.

---

## Возможности

### Вопросы и ответы
- **31 тема, 103 пары «вопрос → ответ»** со всеми формулировками экзаменатора. 27 тем из официального списка, дополнительные вопросы (столица, президент, флаг, ЕС…), поездки и документы, мнение и «неудобные» вопросы, быт.
- **Ответы собираются из анкеты** (11 разделов, 111 полей). Учитываются:
  - род говорящего: παντρεμένος / παντρεμένη, προγραμματιστής / προγραμματίστρια;
  - падежи городов и стран: στη Λεμεσό, από το Κίεβο, στο Μπριάνσκ;
  - даты, возраст, стаж на Кипре, числа, супруг(а), дети, время суток.
- Незаполненные данные подсвечиваются ⟨пропуском⟩, заполнить их можно прямо в карточке.
- Вопросы, которые к вам не относятся (например, про детей, если их нет), в тренировки не попадают.
- Любой ответ можно **переписать вручную** (GR/EN/RU по предложениям) или вернуть шаблон. Можно **добавить свои вопросы** в любую тему.

### Словарь
- **16 колод, 572 слова и фразы**, у каждого есть английский эквивалент:
  - фразы-спасатели (48): «Μπορείτε να επαναλάβετε;», «Πιο αργά, παρακαλώ»…;
  - вопросительные слова, семья, работа, жильё, кипрская кухня, праздники, религия, хобби, распорядок дня, учёба, Кипр и общество, даты и числа;
  - ключевые глаголы в настоящем, прошедшем и будущем времени.
- Колоду «Мои слова и фразы» можно пополнять самостоятельно.

### Режимы тренировки
- **Ежедневное занятие** — карточки с интервальным повторением (SM-2): вопрос → свой ответ, слова в обе стороны. Если задана дата собеседования, интервалы подстраиваются, чтобы всё успело повториться к ней.
- **Симуляция собеседования** — вопрос звучит без текста, в случайной формулировке. Кнопки-подсказки — это греческие фразы-спасатели, их нужно произнести. Есть таймер и самооценка, а в итогах можно повторить слабые вопросы.
- **«Узнай вопрос»** — тренировка понимания на слух: выбрать тему вопроса из 4 вариантов.
- **Шпаргалка** — все ответы на одной странице: печать или PDF в две колонки (около 4 страниц при GR + EN), копирование текста, «Поделиться». Прямая ссылка: `/?open=cheat`.

### Озвучка
- Голос браузера (на iPhone — «Melina»), работает офлайн.
- Облачные нейроголоса **Azure**: мужской Nestoras для экзаменатора, ваши ответы — голосом по вашему роду. Звук кешируется на устройстве. Если сети нет, срабатывает голос браузера.

### Напоминания (Telegram-бот и Web Push)
- Каждый день в выбранное время по вашему часовому поясу, **только если вы сегодня ещё не занимались**. Тихие часы 22:30–08:00.
- В 21:00 второе напоминание «ещё не поздно» (отключается).
- В напоминании — «📅 До собеседования N дней».
- Кнопки под сообщением в Telegram: «⏰ Через час», «✅ Уже позанимался(ась)», «🔕 Сегодня не надо».
- По воскресеньям — итоги недели: дни с занятиями, карточки, минуты, серия.
- Меню `/settings` кнопками: время, вкл/выкл, вечернее, часовой пояс списком или по геолокации. Команды: `/start`, `/time 19:30`, `/on`, `/off`, `/evening`, `/stats` (только для владельца).
- Первые 3 дня бот подсказывает, с чего начать. После пропусков пишет мягче, а после 14 дней без занятий замолкает до итогов недели.
- В PWA те же напоминания приходят push-уведомлениями. На iPhone push работает только у приложения, установленного на экран «Домой» (iOS 16.4+).

## Приватность: какие данные куда попадают

| Данные | Где хранятся |
|---|---|
| Анкета, ответы, ваши правки, прогресс карточек | На устройстве (`localStorage`). В Telegram дополнительно синхронизируются через **ваше личное облако Telegram** (CloudStorage). На наш сервер **не отправляются**. |
| Настройки напоминаний, часовой пояс, дата собеседования, числа занятий за день (карточки, вопросы симуляции, квиз, минуты) | Сервер напоминаний (Postgres на Railway) |
| Telegram id и имя (для бота) | Сервер напоминаний |
| Текст для озвучки (включая ответы) | Azure — только если включена облачная озвучка |
| Анонимная статистика посещений | Vercel Analytics |
| Ошибки (без тел запросов, заголовков и ввода в полях) | Sentry — только если задан DSN |

Для переноса данных между устройствами есть **экспорт и импорт файла** (Настройки → Данные).

## Архитектура

```
┌──────────────── Vercel ────────────────┐        ┌────────── Railway ──────────┐
│  Фронтенд: Vite + React + TS (PWA)     │  HTTPS  │  Сервер: NestJS 11           │
│  • Telegram Mini App / PWA             │ ──────▶ │  • Telegram-бот (вебхук)     │
│  • /api/tts — Vercel Function → Azure  │         │  • крон напоминаний          │
│                                        │         │  • Web Push (VAPID)          │
└────────────────────────────────────────┘         │  • Postgres (TypeORM)        │
                                                   └──────────────────────────────┘
```

- **Фронтенд** (корень репозитория): Vite, React 19, TypeScript, Tailwind v4, zustand, `vite-plugin-pwa`. Работает и без сервера: тогда нет только напоминаний.
- **`api/tts.ts`** — функция Vercel, которая проксирует озвучку в Azure. Ключ хранится на сервере, ответы кешируются CDN.
- **Сервер** (`server/`): NestJS 11, TypeORM + Postgres, `nestjs-telegraf`, `@nestjs/schedule`, `web-push`. Подробности — в [server/README.md](server/README.md).

## Локальная разработка

Нужны Node.js 22+ и Docker (для Postgres).

```bash
# 1. Фронтенд
npm install
cp .env.example .env.local        # VITE_API_URL=http://localhost:3000
npm run dev                       # http://localhost:5173

# 2. Сервер напоминаний (по желанию)
cd server
cp .env.example .env              # TELEGRAM_BOT_TOKEN — если нужен бот
docker compose up -d db           # Postgres на localhost:5433
npm install
npm run dev                       # http://localhost:3000 (без PUBLIC_URL бот работает через polling)
npm test                          # автотесты сервера
```

- Облачная озвучка локально работает только через `npx vercel dev` и ключ Azure в `.env.local`. Без него используется голос браузера.
- Service worker и push работают только в production-сборке: `npm run build && npm run preview`.
- Порт базы 5433 выбран, чтобы не конфликтовать с другими Postgres. Его можно поменять переменной `DB_PORT`.

### Команды

| Где | Команда | Что делает |
|---|---|---|
| корень | `npm run dev` | dev-сервер фронтенда |
| корень | `npm run build` | проверка типов и сборка PWA в `dist/` |
| корень | `npm run preview` | локальный просмотр сборки (с service worker) |
| `server/` | `npm run dev` | сборка и запуск сервера |
| `server/` | `npm test` | тесты: подпись Telegram, расписание напоминаний, тексты |
| `server/` | `docker compose up --build` | база и сервер в контейнерах |

## Переменные окружения

### Фронтенд (Vercel)

| Переменная | Обязательно | Описание |
|---|---|---|
| `VITE_API_URL` | для напоминаний | адрес сервера на Railway, например `https://greek-server.up.railway.app` |
| `AZURE_SPEECH_KEY` | для облачной озвучки | ключ ресурса Azure AI Speech (тариф Free F0 — 500 тыс. символов в месяц) |
| `AZURE_SPEECH_REGION` | для облачной озвучки | регион ресурса, например `westeurope` |
| `VITE_SENTRY_DSN` | нет | Sentry для ошибок фронтенда |

`VITE_*` подставляются при сборке: после их изменения фронтенд нужно передеплоить.

### Сервер (Railway)

| Переменная | Обязательно | Описание |
|---|---|---|
| `DATABASE_URL` | да | `${{Postgres.DATABASE_URL}}` из плагина Postgres |
| `TELEGRAM_BOT_TOKEN` | для бота | токен бота; без него работают только API и push |
| `WEBAPP_URL` | да | адрес фронтенда (кнопка Mini App и CORS) |
| `ADMIN_TG_IDS` | нет | Telegram id владельцев через запятую — для `/stats` |
| `PUBLIC_URL` | нет | адрес сервера для вебхука; на Railway берётся из `RAILWAY_PUBLIC_DOMAIN` |
| `ALLOWED_ORIGINS` | нет | дополнительные origin для CORS через запятую |
| `SENTRY_DSN` | нет | Sentry для ошибок сервера |
| `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT` | нет | если не заданы, ключи генерируются и хранятся в БД |

## Деплой

### Фронтенд → Vercel
1. Импортируйте репозиторий в Vercel. Фреймворк Vite определится автоматически, функция `api/tts.ts` подхватится сама.
2. Задайте переменные из таблицы выше и запустите деплой (или `npx vercel --prod`).

### Сервер → Railway
1. New Project → Deploy from GitHub repo, **Root Directory: `server`**. Сборка идёт по `Dockerfile`, настройки — в `railway.json`.
2. Add → Database → **PostgreSQL**. В сервисе сервера: `DATABASE_URL=${{Postgres.DATABASE_URL}}`.
3. Задайте `TELEGRAM_BOT_TOKEN`, `WEBAPP_URL`, `ADMIN_TG_IDS`.
4. Settings → Networking → **Generate Domain**. Сервер сам зарегистрирует вебхук, команды и кнопку «Тренажёр» в боте.
5. Укажите этот домен во фронтенде в `VITE_API_URL` и передеплойте фронтенд.

Миграции применяются автоматически при старте. **Реплика сервера должна быть одна**, иначе напоминания будут приходить дважды.

## Как устроен код

### Фронтенд (`src/`)

| Путь | Что внутри |
|---|---|
| `data/topics.ts` | темы, формулировки вопросов и шаблоны ответов (функции от анкеты) |
| `data/profile.ts` | поля анкеты, разделы и варианты выбора с греческими формами |
| `data/vocab.ts` | колоды словаря |
| `lib/grammar.ts` | падежи городов и стран, даты, числа, склонения |
| `lib/ctx.ts` | контекст шаблонов: значения анкеты с учётом рода и ⟨пропусков⟩ |
| `lib/srs.ts` | интервальное повторение |
| `lib/tts.ts` | озвучка: браузер и Azure с кешем |
| `lib/telegram.ts` | Telegram Mini App SDK, тема, CloudStorage |
| `lib/api.ts` | клиент сервера напоминаний и Web Push |
| `content.ts` | сборка контента: шаблоны, правки пользователя, свои вопросы, очередь карточек |
| `store.ts` | состояние (zustand + localStorage), миграции сохранённых данных, слияние при синхронизации |
| `sync.ts` | синхронизация через Telegram CloudStorage, экспорт и импорт |
| `screens/` | экраны: главная, занятие, симуляция, квиз, темы, словарь, анкета, настройки, напоминания, шпаргалка |
| `ui/kit.tsx`, `ui/fields.tsx` | общие компоненты и редакторы полей анкеты |
| `public/push-sw.js` | обработчик push-уведомлений в service worker |

### Как добавить контент
- **Вопрос в тему:** добавьте объект в `items` нужной темы в `data/topics.ts`. Нужны `id`, `title`, `questions(c)` (все формулировки) и `answer(c)` (предложения `{ gr, en, ru }`). Значения анкеты берутся через помощники контекста: `c.name()`, `c.city().in`, `c.date()`, `c.g(муж, жен)`. Если вопрос относится не ко всем, укажите `when(c)`. Поля анкеты, от которых зависит ответ, перечислите в `fields`.
- **Поле анкеты:** добавьте его в `FIELDS` в `data/profile.ts`, а значение по умолчанию — в `DEFAULT_PROFILE`. Если меняется тип уже сохранённого поля (например, одиночный выбор становится множественным), добавьте преобразование в `migrateProfile` в `store.ts`.
- **Слово:** добавьте запись в нужную колоду в `data/vocab.ts`. `id` должен быть уникальным и не меняться: к нему привязан прогресс. Женскую форму указывайте в `grF`.
- **Город или страна:** добавьте их в `CITIES`, `COUNTRIES` или `DESTINATIONS` в `lib/grammar.ts`, указав винительный падеж с артиклем (`το Μπριάνσκ`) и русские формы.

## Известные ограничения
- В Telegram на Android голос браузера часто недоступен. Нужна облачная озвучка, либо откройте приложение как PWA в Chrome.
- Прогресс в Telegram Mini App и в PWA раздельный. Перенести его можно экспортом и импортом файла.
- Кнопки «Через час / Уже / Не надо» есть только в Telegram, в push-уведомлениях PWA их нет.
- Печать шпаргалки внутри Telegram недоступна, там работает копирование текста.
